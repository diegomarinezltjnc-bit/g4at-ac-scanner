# g4at·ac — Scanner

Cliente de Windows del anticheat **g4at·ac**. El código fuente está en `scanner/`.

El `.exe` se compila **automáticamente** con GitHub Actions (runner Windows) y se
publica en **Releases** → `scanner-latest`. No necesitas compilar nada a mano.

- Panel: https://g4atac.shop
- La licencia se inyecta al compilar desde el secreto `LICENSE_KEY` (Settings → Secrets → Actions).
